# EZ Scanner

**پیدا کردن آی‌پی‌های تمیز کلادفلر برای تانل‌های SNI — با یک رابط گرافیکی قدرتمند و یک CLI کامل.**
Clean-IP discovery for Cloudflare fronted tunnels (vless / vmess / trojan / BPB style), with a local GUI, a scriptable CLI, resumable scans and honest diagnostics.


## چرا این پروژه؟

بسیاری از کاربران اسکنرهای مشابه به این نتیجه رسیده‌اند که «هیچ آی‌پی سبزی پیدا نمی‌شود» یا «تست سرعت همه را قرمز می‌زند». دلیلش معمولاً خرابی موتور نیست، بلکه **گیت‌های سخت‌گیرِ پیش‌فرض و تکراری** است:

| مشکل رایج | علت واقعی | EZ Scanner چه می‌کند |
|---|---|---|
| همه قرمز، حتی آی‌پی‌های سالم | بررسی WebSocket و نگه‌داشتن بیکار به‌طور پیش‌فرض **روشن** بودند | هر دو **خاموش** هستند و با یک کلیک روشن می‌شوند |
| تست سرعت همیشه ناموفق | با ۱ تلاش، شرط «۲ تلاش موفق» هرگز برآورده نمی‌شد | گیت‌ها صریح، قابل شمارش و تست‌شده‌اند (`minSuccesses`) |
| پیدا کردن SNI | فیلد SNI در GUI نبود | فیلد SNI + تحلیل خودکار لینک کانفیگ |
| خروجی گرفتن از نتایج | کپی/اکسپورت کار نمی‌کرد | CSV، XLSX، JSON، TXT، NDJSON، کلیپ‌بورد و **ساخت کانفیگ آماده** |
| قطع شدن اینترنت وسط اسکن | اسکن بسیار پرحجم و بدون محدودیت نرخ | محدودیت نرخ، تأخیر، backoff خودکار و **توقف خودکار وقتی خط می‌رود** |
| اسکن ساعت‌ها طول می‌کشد و اگر قطع شود از صفر شروع می‌شود | نشستی ذخیره نمی‌شد | نشست‌ها هر ۱۵ ثانیه + snapshot و **ادامه از همان‌جا** |
| کپی‌پیست لیست آی‌پی یا دامنه امکان نداشت | فقط فایل متنی | پیست لیست، CIDR، رنج، `ip:port`، دامنه و لینک کانفیگ |

نگاشت کامل با ایشوهای ریپوی مرجع: [`docs/ISSUES.md`](docs/ISSUES.md)

## نصب / Install

نیاز: **Node.js 22.18 یا بالاتر** (۲۴ LTS توصیه می‌شود). هیچ کامپایلر، WebView یا وابستگی سیستمی لازم نیست.

```bash
git clone https://github.com/ezzaeskardi-afk/EZ_scanner.git
cd EZ_scanner
npm install            # فقط typescript + @types/node
npm start              # GUI را روی http://127.0.0.1:8788 باز می‌کند
```

یا نصب سراسری برای دستور `ezscan`:

```bash
npm install -g .
ezscan gui
```

ویندوز: فایل `start-gui.cmd` را دوبار کلیک کنید. لینوکس/مک: `./start-gui.sh`.

## رابط گرافیکی

`npm start` سرور محلی را روی `127.0.0.1` بالا می‌آورد و مرورگر را باز می‌کند. نکات امنیتی: فقط لوپ‌بک، هر درخواست تغییردهنده نیازمند توکنِ همان اجرا، و درخواست‌های cross-origin رد می‌شوند (تست‌شده).

بخش‌های GUI:

1. **تنظیمات اسکن** — پریست‌ها، منبع آی‌پی، تمام پارامترهای پروب، تست سرعت و ایمنی.
2. **پیشرفت** — فاز جاری، درصد، نرخ، ETA، تعداد سالم/ناموفق و **تفکیک علت خطاها** (`timeout: 18, reset: 3, …`).
3. **نتیجه‌ها** — جدول زنده با مرتب‌سازی، فیلتر، انتخاب گروهی، کپی سریع، پروب/تست سرعت مجدد و «اسکن فقط همین‌ها».
4. **داشبورد OpenUI** — گزارش تصویری (KPI، نمودار پینگ، جدول تمیزترین آدرس‌ها، تفکیک خطاها) که از کد **OpenUI Lang** ساخته و با رندرر رسمی پروژه‌ی [OpenUI](https://github.com/thesysdev/openui) کشیده می‌شود؛ فایل‌هایش محلی‌اند (بدون CDN) و فقط وقتی اسکنی انجام شده باشد بارگذاری می‌شوند.
5. **خروجی** — CSV / XLSX / JSON / TXT / فقط آی‌پی‌ها + ساخت کانفیگ آماده از روی لینک شما.
6. **ابزارها** — نشست‌های ذخیره‌شده (ادامه/دانلود/حذف/ورود از فایل)، عیب‌یابی خط، لاگ زنده و راهنمای سریع.

تم روشن/تیره با دکمه‌ی کنار `EN` عوض می‌شود و همان‌جا ذخیره می‌ماند. فایل‌های استاتیک با gzip سرو می‌شوند (باندل OpenUI از ۳.۶ مگابایت به حدود ۱ مگابایت می‌رسد) و فایل‌های نسخه‌دار با `?v=` برای یک هفته کش می‌شوند.

پریست‌ها:

| پریست | حالت | تلاش/موفقیت | ورکر | WS | Idle | ایمنی |
|---|---|---|---|---|---|---|
| `fast` | tcp | 1/1 | 200 | خاموش | خاموش | بدون محدودیت |
| `standard` | tls | 3/2 | 50 | خاموش | خاموش | بدون محدودیت |
| `strict` | http | 4/3 | 40 | روشن | 1.5s | بدون محدودیت |
| `gentle` (ایران) | tls | 2/1 | 20 | خاموش | خاموش | ۱۲ اتصال/ثانیه + ۴۰ms تأخیر |

## خط فرمان

```bash
ezscan gui                                     # رابط گرافیکی
ezscan scan --preset gentle --count 2000 --sni my.sni.example --csv out.csv
ezscan scan --source config --config "vless://…" --speed --xlsx found.xlsx
ezscan scan --source paste --targets my-ips.txt --csv out.csv   # فقط فاز تست
ezscan resume a1b2c3d4                         # ادامه‌ی نشست
ezscan sessions                                # فهرست نشست‌ها
ezscan export a1b2c3d4 --format links --link-template "vless://…" --out links.txt
ezscan doctor                                  # DNS/TCP/TLS/HTTP/سرعت
ezscan selftest                                # «مشکل از خط من است یا تنظیمات؟»
ezscan config "vless://…"                      # SNI/پورت/ترانسپورت کانفیگ
ezscan scan --help                             # همه‌ی گزینه‌ها
```

خروجی ترمینال برای افراد کم‌بینا هم قابل استفاده است: وضعیت‌ها با نماد `[OK]`/`[--]`/`[!!]` مشخص می‌شوند، نه فقط رنگ (`--no-color`, `NO_COLOR`).

## گیت‌ها: چه چیزی بررسی می‌شود؟

هر «تلاش» تا جایی پیش می‌رود که شما اجازه داده باشید:

```
اتصال TCP → دست‌دادن TLS → پاسخ HTTP/1.1 → آپگرید WebSocket → نگه‌داشتن بیکار
  (همه)        (پیش‌فرض)        (پیش‌فرض روشن)      (پیش‌فرض خاموش)      (پیش‌فرض خاموش)
```

| گیت | پیش‌فرض | معنی | چه زمانی روشن کنید |
|---|---|---|---|
| `requireHttp` | ✅ | یک پاسخ HTTP معتبر از لبه بگیرد (سرعت واقعی مسیر) | همیشه، مگر اینکه حالت `tcp` بخواهید |
| `requireWs` | ❌ | آپگرید WebSocket با کد ۱۰۱ | فقط اگر کانفیگ‌تان واقعاً `ws` است |
| `stabilityMs` | `0` (خاموش) | اتصال بی‌کار بماند و اگر DPI آن را قطع کرد، رد شود | بعد از اینکه نتیجه‌های اولیه را گرفتید |
| `minSuccesses` | `2` از `3` | چند تلاش باید موفق شود | برای خط‌های پرنوسان `1` |
| `earlyExit` | ✅ | به‌محض رسیدن به حد نصاب، بقیه‌ی تلاش‌ها حذف می‌شود | همیشه (سرعت اسکن چند برابر) |
| `maxLossPct`, `maxLatencyMs`, `minScore` | 50 / 1800 / 45 | آستانه‌های کیفیت | بر اساس نیاز |

اگر چیزی نگیرید: پریست **ملایم** را بزنید، `minScore` را روی `0` بگذارید و `ezscan doctor` را اجرا کنید.

## ایمنی خط و ضد‌شناسایی

اپراتورها به اسکن پرحجم با قطع کامل اینترنت پاسخ می‌دهند. سه لایه محافظت:

- **محدودیت نرخ سراسری** (`rateLimitPerSec`) و **تأخیر هر ورکر** (`minDelayMs`).
- **کاهش خودکار سرعت**: نسبت خطا با میانگین متحرک رصد می‌شود و در صورت بالا رفتن، فاصله‌ی بین پروب‌ها زیاد می‌شود.
- **نگهبان خط**: هر چند ثانیه به سه canary (‏1.1.1.1:443، 8.8.8.8:53، 9.9.9.9:443) اتصال TCP آزمایشی زده می‌شود؛ اگر خط برود، اسکن پارک و پس از بازگشت خودکار ادامه می‌یابد.

همچنین اگر SNI همان دامنه‌ی خودتان باشد، هشدار داده می‌شود (اسکن با دامنه‌ی شخصی، ریسک فیلتر شدن آن دامنه را بالا می‌برد) — راهکار پیشنهادی: با یک SNI عمومی اسکن کنید و بعد آدرس را در کانفیگ خودتان جایگزین کنید؛ همان کاری که «ساخت کانفیگ‌ها» انجام می‌دهد.

## خروجی‌ها

| قالب | کاربرد |
|---|---|
| `txt` | `ip:port` در هر خط (آی‌پی‌های v6 داخل براکت) |
| `hosts` | فقط آدرس‌ها |
| `csv` | ۲۰ ستون با BOM برای Excel، شامل دلیل رد شدن |
| `xlsx` | فایل واقعی اکسل، بدون هیچ کتابخانه‌ی بیرونی (ZIP ذخیره‌ای + CRC32) |
| `json` / `ndjson` | برای اسکریپت و اتوماسیون |
| `links` | لینک آماده‌ی وارد کردن در کلاینت: `vless://…@<ip>:443?…#EZ-<ip>-<latency>` |

## نشست‌ها و ادامه‌ی اسکن

هر اسکن به‌صورت خودکار در `~/.ez-scanner/sessions/` ذخیره می‌شود (هربار ۱۵ ثانیه، و در پایان/توقف/توقف موقت). هر snapshot شامل تنظیمات، لیست کامل آدرس‌ها، موقعیت (cursor)، نتیجه‌ها و نمونه‌ی خطاها است. با `--resume` یا دکمه‌ی «انتخاب و ادامه» دقیقاً از همان آدرس ادامه داده می‌شود، حتی بعد از ری‌استارت سیستم.

## پرسش‌های رایج

**هیچ آی‌پی پیدا نمی‌شود.** `ezscan doctor` و بعد `ezscan selftest` را اجرا کنید؛ خروجی می‌گوید مشکل از خط است یا از گیت‌ها. اگر selftest سالم بود، `minScore` را `0` کنید و WS/Idle را خاموش نگه دارید.

**چرا سرعت اندازه‌گیری‌شده با سرعت کانفیگ فرق دارد؟** اینجا مسیر مستقیم تا لبه اندازه‌گیری می‌شود (پروکسی اجرا نمی‌شود) و صرفاً برای **رتبه‌بندی** آی‌پی‌هاست. عدد نهایی را در کلاینت خودتان ببینید.

**روی موبایل کار می‌کند؟** GUI داخل هر مرورگری باز می‌شود؛ اگر Node روی لینوکس/ترموکس نصب باشد، GUI را با `ezscan gui --no-open` اجرا کنید و آدرس را در مرورگر گوشی همان شبکه باز کنید (سرور فقط لوپ‌بک را می‌پذیرد، برای دسترسی از شبکه `EZSCAN_HOST` را تغییر دهید).

## معماری

```
src/
  core/      موتور بدون وابستگی: probe، scoring، ipsrc، ratelimit، scanner، export، zip/xlsx، openui
  server/    HTTP + SSE محلی برای GUI  +  doctor/selftest
  gui/       رابط کاربری بدون build (HTML/CSS/JS خالص، راست‌به‌چپ، EN/FA) + vendor/openui
  cli/       خط فرمان
test/        78 تست: پروب روی سرور TLS محلی، توقف/ادامه، snapshot، API و امنیت، خروجی‌ها، گزارش OpenUI
```

فلسفه‌ی طراحی: **هیچ وابستگی رانتیای وجود ندارد** (فقط devDependencies برای تایپ‌چک)، TypeScript با type-stripping خودِ Node اجرا می‌شود، و منطق تصمیم‌گیری (scoring) به‌صورت توابع خالص و تست‌شده است. تنها «کتابخانه»ی همراه، فایل‌های از پیش ساخته‌شده‌ی OpenUI است که برای کارکرد آفلاین داخل `src/gui/vendor/openui` قرار گرفته‌اند.

## داشبورد OpenUI

بخش «داشبورد OpenUI» در GUI از [OpenUI](https://github.com/thesysdev/openui) استفاده می‌کند — زبان UI و رندرر آن — تا نتیجه‌ی اسکن به‌جای یک جدول خشک، یک گزارش تصویری باشد:

- `src/core/openui.ts` از وضعیت اسکن (KPI‌ها، هیستوگرام پینگ، آدرس‌های تمیز، علت خطاها، گیت‌های فعال) یک سند **OpenUI Lang** می‌سازد:

```
root = Card([header, verdict, kpis, gates, chartHeader, chart, topHeader, topTable, failsTable])
verdict = Callout("success", "Scan produced clean addresses", "5 address(es) passed every gate. …")
kpis = SnippetCardBlock([kpi1, kpi2, kpi3, kpi4, kpi5], "grid", true)
chart = BarChart(chartLabels, [chartSeries], "grouped", "latency bucket", "Addresses")
```

- صفحه‌ی `src/gui/report.html` همان سند را با `Renderer` و `openuiChatLibrary` رسمی رندر می‌کند (به‌صورت iframe، تا استایل‌های OpenUI با رابط اصلی قاطی نشود).
- دکمه‌ها: **بازخوانی**، **تب جدید**، **کپی کد Lang**، **دانلود کد Lang** — با `GET /api/report/openui?lang=fa|en&top=25&download=1`.
- رندرر داخل `src/gui/vendor/openui/` نگه‌داری می‌شود، پس **هیچ CDN‌ای لازم نیست** (روی خطوطی که jsDelivr/unpkg فیلتر است هم کار می‌کند).
- کد Lang با JSON هم قابل استفاده است: می‌توانید همان گزارش را در OpenUI Playground یا هر اپ OpenUI دیگری پیست کنید.

## تست‌ها / Tests

```bash
npm run typecheck
npm test          # 78 tests: probe engine, gating, pause/resume, snapshot, exports, HTTP API, OpenUI report
```

تست‌ها یک «لبه‌ی جعلی» محلی (TLS + WebSocket + سرور کند/قاتل) بالا می‌آورند و موتور را بدون نیاز به اینترنت واقعی می‌سنجند؛ یک اسکن واقعی هم روی آی‌پی‌های کلادفلر در `npm run selftest` قابل اجراست. تست‌های `test/openui.test.ts` خودشان گرامر OpenUI Lang را اعتبارسنجی می‌کنند (هر خط `id = expr`، هیچ شناسه‌ای تعریف‌نشده نماند، طول ستون‌های جدول برابر باشد، فقط کامپوننت‌های کتابخانه‌ی رسمی استفاده شوند).
